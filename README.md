# Medical Expert System - Запись к врачу

Медицинская экспертная система для рекомендации врача-специалиста на основе выбранных симптомов.

## Описание

Система оперирует базой медицинских специализаций (8 врачей). Процесс сбора анамнеза иерархичен: сначала выбираются общие категории жалоб, затем происходит уточнение локализации или характера.

### Возможности

- Иерархическое меню выбора симптомов (7 категорий, 26 симптомов)
- Выбор симптомов через графический интерфейс
- Отмена выбранных симптомов (крестики)
- Полный сброс анкеты (кнопка RESET)
- Определение врача по трём правилам:
  1. Экстренный случай (красные флаги)
  2. Точное совпадение ключевого симптома
  3. Накопительный рейтинг по весам (минимум 3 симптома)
- Экран результатов с рекомендованным врачом
- Экран с подробным объяснением (правило и симптомы)
- Обработка ошибок конфигурации (дубликаты ID, циклы, отсутствие файлов)

## Требования

- GHC (Glasgow Haskell Compiler) 9.6 или выше
- Cabal 3.0 или выше
- Библиотеки: gloss, text, containers, yaml, aeson, directory

## Установка и запуск

### 1. Клонирование репозитория

git clone https://github.com/mariealanie/medical-booking.git
cd medical-booking

### 2. Сборка проекта

cabal build

### 3. Запуск

cabal run

Или с указанием своих конфигурационных файлов:

cabal run mariabooking -- path/to/doctors.yaml path/to/symptoms.yaml

## Формат конфигурационных файлов

### doctors.yaml

- doctorName: Cardiologist
  doctorProfile: Heart diseases
  keySymptoms: [chest_pain, arrhythmia]
  symptomWeights: {chest_pain: 10, arrhythmia: 9}
  isEmergency: true

### symptoms.yaml

nodeId: root
nodeName: Main Menu
children:
  - nodeId: pain
    nodeName: Pain
    children:
      - nodeId: headache
        nodeName: Headache
        children: []

## Управление

- Клик по симптому — выбрать симптом или перейти в подменю
- Клик по крестику — удалить выбранный симптом
- TO DOCTOR — запустить диагностику
- RESET — сбросить все выбранные симптомы
- BACK — вернуться на уровень выше
- REASON — показать подробное объяснение
- Стрелки ↑↓ — прокрутка списков
